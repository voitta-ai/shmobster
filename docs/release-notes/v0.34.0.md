# shmobster v0.34.0

One change: diagnose and survive a whole-interpreter freeze.

## What an upgrade requires

Nothing. No new required config key; `agent.heartbeat_path` is optional (temp
default). To get the auto-restart, install the launchd health-check from
`deploy/ai.shmobster.healthcheck.plist.sample`.

## A freeze the in-process watchdog cannot see (#66 follow-up)

2026-10-03: the agent went deaf for 46 minutes with the process up at 0% CPU, no
host sleep, and the watchdog neither firing nor logging. That is not the
socket-level wedge the #66 watchdog detects (session stable, pong fresh,
processor alive) -- it is the whole interpreter frozen, which freezes the
watchdog thread too. A restart recovered it; nothing diagnosed it.

Two layers, neither guessing at the mechanism:

- **faulthandler on SIGUSR1.** `kill -USR1 <pid>` dumps a traceback for every
  thread to stderr, so the next freeze is one command from showing which thread
  is stuck and where. Armed at startup; free until the signal arrives.
- **An out-of-process heartbeat.** A daemon thread stamps a file every 15s, and
  `deploy/health-check.sh` (run from launchd, sample plist included) restarts the
  service when the stamp goes stale. The heartbeat's value is that it stops when
  the interpreter freezes -- an external check catches what an in-process one
  cannot, and unlike "the log went quiet" a timer heartbeat does not
  false-positive on an idle bot. Optional `agent.heartbeat_path`.

Also fixes a brittle regain-date test that broke CI on 2026-10-05 (a hard-coded
date that parsed as past once it became "today"); it is now computed relative to
now.
