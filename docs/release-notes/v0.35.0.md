# shmobster v0.35.0

Two prompt changes from the #demo1 rehearsal on 2026-10-06: the model now knows
today's date, and a channel can make a skill part of every turn instead of a
menu entry the model may skip.

## What an upgrade requires

Nothing. `always_skills` is an optional channel policy key; a channel without it
behaves as before.

## Channel policy `always_skills` (#318)

A channel skill reaches the model as a one-line menu entry, and loading it is the
model's choice. In #demo1, "Anything from Harbor Point in our email or
contracts?" loaded the channel's format skill in 2 of 5 turns, with the same
model and config and prompts within a few tokens of each other. Without the
skill, the answer dropped the CRM link and the CRM / Documents labels.

`always_skills` lists skill names whose full text goes into that channel's
system prompt on every turn, under "Standing procedures for this channel":

    "always_skills": ["active-client-status"]

It is a policy key and not skill front matter, so a skill proposed through
learning (#129) cannot make itself standing. An unknown name is skipped with a
warning. Each listed skill costs its length on every turn in the channel.

## Today's date in every prompt (#316)

The system prompt carried no date, so date reasoning was a guess: a reply on
2026-10-06 called 2026-10-13 "in the past". The identity block now says
`Today is <Weekday>, <YYYY-MM-DD> (<TZ>).`, computed per turn from host-local
time, so a long-running process does not go stale at midnight.
