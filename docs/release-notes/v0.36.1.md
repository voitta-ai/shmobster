# shmobster v0.36.1

The watchdog stops restarting the agent while the host sleeps.

## What an upgrade requires

Nothing.

## Host sleep is not deafness (#322)

On a laptop with Power Nap, every watchdog exit over one night landed in a macOS
DarkWake: the process ran for ~45s on a socket Slack had already dropped, no
session could stabilise, and the unstable time added up across windows until it
passed the limit. Each poll now compares the wall-clock gap with the monotonic
gap; when the wall clock ran ahead by more than a poll interval, the host was
suspended, and the watchdog restarts its clocks
(`watchdog: host slept ~Ns; clocks restarted`). A CPU-starved process moves both
clocks, so a thrashing host still counts as a stall.

The status line's `stable_for=` was the seconds WITHOUT a stable session; it is
now labelled `unstable_for=`. A healthy agent shows `unstable_for=0s`.
