# shmobster v0.36.2

`npm ls` runs without an approval card.

## What an upgrade requires

Nothing.

## `npm ls` is a read (#325)

YOLT 2.x answers `unknown` for npm, so `npm ls -g` parked for a card. `npm
ls`/`list` read the local node_modules tree, with no network and no scripts, and
now run. `npm view`/`outdated` still park: they reach whatever registry a
`.npmrc` in the channel tree names, a host nothing vets against
`allow_domains`. `vercel` parks entirely until it becomes a per-channel,
project-scoped grant.
