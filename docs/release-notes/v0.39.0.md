# shmobster v0.39.0

Three more reads run without a card, and the agent stops ending tasks early.

## What an upgrade requires

Nothing. No config or policy keys change.

## The grant layer (#342)

- **awk that only reads.** awk becomes a flag-checked read with an allowlist
  for its program:
  - Only allowlisted builtin calls (`print`, `printf`, `length`, `substr`,
    `split`, `sub`/`gsub`, `match`, `sprintf`, the math functions, ...) are
    accepted.
  - Any other BWK awk or gawk builtin name parks wherever it appears, called
    or bare.
  - `|` (except `||`), `>`, `@`, a backslash outside a literal, `function`,
    and every option except `-F` and `-v` park.
  - The program must be a single-quoted string or a plain word.
- **An interpreter's version.** `python3 --version` / `-V` (and `python`) on
  its own is granted. Any other interpreter use parks as before.
- **Unattended channels: `curl -o FILE`.** A fetch to a host in `allow_domains`
  may write the response to a file the command names (`-o` / `--output`). The
  sandbox confines it like the channel's other uncarded writes. Names the
  server chooses (`-O`, `-J`, `--remote-name*`, `--output-dir`) still park, and
  attended channels are unchanged.

## The agent (#342)

`SOUL.md`: finish the task. A clean boundary in the work, or the tool-step
limit, is not a reason to stop mid-task. The loop enforces the limit and says
so when it is reached.
