# shmobster v0.41.0

Attachments land on disk byte-identical, more read-only shell shapes run without a card, and the grant layer closes several ways a "read" could run code, write or reach the network.

## What an upgrade requires

- No config, dependency or pin changes; the yolt pin stays at v2.17.0.
- **Attachments are written to disk** (#407) in channels whose policy sets a `cwd` of its own: under `<cwd>/.attachments/<file id>/<name>`, with a `.gitignore` inside that folder so it never shows in `git status`. Nothing removes them; delete the folder by hand when it grows.
- **Some shapes that ran without a card now park** (see "Tightened" below). A channel that relied on them gets a card instead.

## Attachments on disk (#407, closes #372)

- A Slack attachment on the message that started a turn (and on its resume) is saved byte-identical, and the model is told its path relative to the working directory, its size and sha256. Same type and size caps as before (text and images, 5 MB), downloaded only from Slack with the token shmobster already uses; the agent gets no token and no new domain.
- Saved only where the conversation's policy (directly or through its `link`) sets a `cwd` of its own, distinct from `default_policy`'s and `exec.cwd`: those are shared, so one person's file would be readable from another's turn. Never into shmobster's own checkout, runtime files or config folder.
- A file that cannot be saved is said so, never swallowed. The agent never rebuilds a file by retyping it: it copies the saved one, or says there is no copy and stops.
- Files are 0600 in 0700 folders; names are reduced to one safe path component.

## More reads without a card (#408, #409; closes #373, #374)

- `awk` with an attached quoted option value (`awk -F'","' '{print $6}' f`), still with a single-quoted program from the allowlist.
- `brew list --versions [formula…]`, for names in formula grammar only.
- A read-only `for x in <literals or globs>; do <reads>; done` loop, with no redirect to a file.
- A command substitution as a whole argument after a literal `--`, when the command inside and the command taking it are both reads (`git log --oneline -- $(git ls-files '*.py')`). `git grep` still parks: it is not a granted read.

## Tightened: closed holes, and shapes that now park

- **Shell arithmetic is code.** `$((…))`, `$[…]` and `${…}` with an operator (offset, subscript, `:-`, indirection) can run a command through an array subscript in a variable's value, including a filename. They now park everywhere; before this release `echo $((_))` after an `echo` of a crafted string ran.
- **gawk network files.** An awk operand naming `/inet…` or `/p/inet…`, and a program touching `ARGV`/`ARGC`, park: gawk would open a socket.
- **awk:** a bare unquoted program (`awk NF f`) and a glob as an option value park.
- **brew:** a name that is a path, URL, `.rb` file or bottle archive parks.
- **file:** `-C` / `--compile` anywhere in the arguments parks (it writes compiled magic files); `file` with a glob or variable argument parks.
- **`--` must really end the options:** `--end-of-options` is not accepted as a marker, and a `--` that is an option's value does not count.
- Unquoted heredocs and herestrings containing `${x:-default}` now park.

## Also

- **Signal approval cards** in a group say to quote the card or write "`<label>` approve `<id>`": a bare "approve" there reaches no agent. The model no longer names its internal approve tool to people (#406).
- **README:** finding a Signal ACI for `trusted_users` and `persons` through the gateway's members list (#405).
- **Linux health check** reads the heartbeat's mtime with GNU `stat` first, so it no longer fails on every run there (#410).
