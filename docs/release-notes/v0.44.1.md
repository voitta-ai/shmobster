# shmobster v0.44.1

The agent stops denying it can see an image it was just sent.

## What an upgrade requires

- Nothing: no config, dependency or pin changes.

## Attached images (#437)

- **Each attached image is labelled** with its name and the fact that it was sent as an image, and a turn carrying images gets a short system section after the conversation history.
- **Why:** in a long thread (a Signal group is one), the agent's own earlier answers from before images reached it ("I can't read images") stayed in the history, and with a bare image and no word about it the model described the picture while insisting it had no vision.
- **The wording says "sent", not "you can see it".** Some gateway routes accept an image and silently drop it; a flat visibility claim would push them to invent a description. The model is told to describe what it sees, or say it cannot and not guess.
- **The Codex text-only fallback** is told plainly that the image was not shown to it.
