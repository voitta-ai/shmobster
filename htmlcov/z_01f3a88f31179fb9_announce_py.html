1"""Announce a version change once, on the first boot after an upgrade (#77). 

2 

3An instance is restarted constantly -- the watchdog does it, launchd does it -- 

4so "announce on boot" would be noise. The signal is a *version change*: the 

5last announced version is persisted, and only a difference is worth saying. 

6 

7No state file does NOT mean "stay quiet". Every deployment that predates this 

8feature has no state, and the first boot after pulling it is precisely the 

9upgrade worth announcing -- staying silent there would skip the only rollout 

10this feature was written for. So an unrecorded previous version announces too, 

11in a shape that does not claim to know where it came from. The cost is one 

12extra message on a genuinely new install, which tells that channel which build 

13just joined it -- worth saying anyway. 

14 

15Ingest-agnostic on purpose. This module knows nothing about Slack; it takes a 

16`post(text)` callable, so a second ingest mode (email, CLI, whatever comes) gets 

17upgrade announcements by passing its own poster. See CLAUDE.md -- a new ingest 

18that skips this is a mode where operators stop hearing about upgrades.""" 

19import logging 

20 

21from . import __version__, build, state 

22 

23_RELEASE_URL = "https://github.com/voitta-ai/shmobster/releases/tag/v{version}" 

24 

25 

26def message(previous): 

27 """The announcement text. `previous` is the version last announced, or None 

28 when this instance has never recorded one -- an install that predates the 

29 state file, or a new deployment. Those are indistinguishable from here, so 

30 the wording claims only what is known.""" 

31 url = _RELEASE_URL.format(version=__version__) 

32 # Standard Markdown, as model replies are: each ingest renders it for its 

33 # surface (a Slack markdown block; Signal styles through the gateway). 

34 # Slack mrkdwn here reached Signal raw (#397). 

35 if previous is None: 

36 retval = ( 

37 f"\u2728 now running **shmobster v{__version__}** " 

38 f"-- [release notes]({url}). Build `{build()}`." 

39 ) 

40 else: 

41 retval = ( 

42 f"\u2728 upgraded to **shmobster v{__version__}** (from v{previous}) " 

43 f"-- [release notes]({url}). Now running `{build()}`." 

44 ) 

45 return retval 

46 

47 

48def check(post): 

49 """Announce via `post(text)` if this instance is running a version it has not 

50 announced before. Returns the text posted, or None. 

51 

52 A missing state file is announced, not swallowed: an install that predates 

53 the state file looks exactly like a fresh one from here, and staying quiet 

54 would skip the first real upgrade to this feature. The message just does not 

55 claim a previous version it does not have.""" 

56 previous = state.get("announced_version") 

57 if previous == __version__: 

58 retval = None 

59 return retval 

60 text = message(previous) 

61 try: 

62 post(text) 

63 except Exception: 

64 # Do not record: an announcement that failed to post should be retried 

65 # on the next boot rather than silently skipped. 

66 logging.exception("announce: could not post upgrade notice") 

67 retval = None 

68 return retval 

69 state.put("announced_version", __version__) 

70 logging.info("announce: %s -> %s announced", previous or "(unrecorded)", __version__) 

71 retval = text 

72 return retval
