1"""Multi-vendor waterfall via LiteLLM Router, built from config.WATERFALL. 

2 

3Iter 0: ordered failover (primary -> fb0 -> fb1 -> ...) with a cooldown so a 

4rate-limited/broken vendor is skipped for a window instead of re-hit every call. 

5Per-vendor observability + dead-fallback surfacing is Iter 3 (#5). 

6 

7Budget parking (#80). LiteLLM decides cooldowns by HTTP status and cools only 

8429/401/408/404 -- see `_is_cooldown_required`. Budget exhaustion is neither: 

9Anthropic answers a usage cap with 400, OpenRouter answers no-credit with 402. 

10Fallback still works, so requests are answered, but the dead vendor is re-dialled 

11on every single turn for as long as the cap lasts -- weeks, in the case that 

12prompted this. So we park it ourselves. 

13 

14Parking hangs off litellm's failure callback, NOT off an `except` around 

15`router.completion()`. When a fallback succeeds the Router returns that 

16response and the primary's exception never propagates -- verified live: 

17OpenRouter 402 as primary, gemini answering, no exception raised, and the 

18failure callback firing with the 402. An `except` here would only see the case 

19where the whole chain is dead, which is the case parking cannot help. 

20 

21Parking rebuilds the Router without that vendor rather than reaching into 

22litellm's private cooldown: the group names here are positional (`primary`, 

23`fb0`, ...) and `complete()` asks for `primary` by name, so dropping the primary 

24is a *renaming*, not a deletion. Rebuilding is also public API, so a litellm 

25upgrade cannot break it. Expiries live in the state file, because a watchdog 

26restart would otherwise un-learn everything. 

27 

28Cost of a rebuild: litellm's in-memory 429 cooldowns for the other deployments 

29reset. They cool for 60s; this is a rounding error against re-dialling a vendor 

30that is dead for a month. 

31 

32Dead rungs (#353). A rung whose model the vendor has retired, dropped from a 

33free tier, or refuses for this plan will not work again until someone edits the 

34config. litellm cools a 404 for 60s and a 400 not at all, and when a later rung 

35covers the failure nothing raises -- so these sat unnoticed for days, until 

36every rung died at once and the agent went silent. A dead rung is parked like a 

37budget-exhausted one, logged at ERROR, and announced once on Slack, after the 

38next turn's reply (`claim_dead_notices`). The park is keyed to the rung's configured model, so 

39fixing the config un-parks it at once. It starts short and doubles on each 

40repeat (`_DEAD_PARK_FIRST` up to `_DEAD_PARK_MAX`), rather than lasting until 

41restart: the watchdog restarts this process routinely, which would re-learn 

42(and re-pay) the failure every few minutes. Short first, because a rung can be 

43fixed vendor-side (access enabled, credit added) with no config edit to notice; 

44growing, because a rung that really is gone should not be re-dialled hourly. 

45 

46A short wait before falling over (#351). A 429 that says when to come back -- 

47Gemini's RetryInfo `retryDelay`, or a Retry-After header -- is a per-minute 

48quota, not an outage, and litellm does not wait it out: it cools the deployment 

49and falls over at once. When every rung after it is dead too, a 29-second 

50quota ends the turn. So `complete()` asks the primary alone first, and on a 

51429 with a stated delay of at most `_RETRY_WAIT_CAP` waits and asks it once 

52more, directly, before handing the request to the rest of the chain. The 

53Router's fallbacks therefore start at `fb0`: the primary is never in them."""

153# The longest stated 429 delay worth waiting out on the primary (#351). A 

154# per-minute quota names a delay under a minute; anything longer is an hourly or

156# the primary much later. 60s is also what litellm cools a 429 for here

164_RETRY_DELAY = re.compile(r"retryDelay\W{0,4}(\d{1,6}(?:\.\d{1,6})?)s\b")

176def _dead_records(): 

177 """Every dead-rung record that still applies, in force or not: recorded 

178 against the model the rung is configured with now, and not yet past its 

179 history window. Pruned on read; a park running out is logged once.""" 

180 with _DEAD_LOCK: 

181 now = time.time() 

182 _kept, changed = _prune_dead(state.get(_DEAD_KEY) or {}, now, []) 

183 if changed: 

184 notes = [] 

185 pruned, ok = state.update(_DEAD_KEY, lambda raw: _prune_dead(raw or {}, now, notes)[0]) 

186 # A failed write hands back the unpruned value; keep using the 

187 # pruned view computed above, and retry the write on the next read. 

188 retval = pruned if ok else _kept 

189 for line in (notes if ok else []): 

190 logging.info(line) 

191 else: 

192 retval = _kept 

193 return retval

196def _prune_dead(raw, now, notes): 

197 """(kept records, whether anything changed). Pure apart from appending log 

198 lines to `notes`, so it can run inside a state.update callback.""" 

199 models = {v.get("name"): v.get("model") for v in config.WATERFALL} 

200 kept, changed = {}, False 

201 for name, rec in raw.items(): 

202 if not (isinstance(rec, dict) and isinstance(rec.get("until"), (int, float))): 

203 changed = True 

204 continue 

205 if rec.get("model") != models.get(name): 

206 changed = True 

207 if rec["until"] > now: 

208 notes.append(f"waterfall: {name}'s config changed; out of its dead-rung park") 

209 continue 

210 if rec["until"] + _DEAD_PARK_MAX <= now: 

211 changed = True 

212 continue 

213 if rec["until"] <= now and not rec.get("back"): 

214 rec = dict(rec, back=True) 

215 changed = True 

216 notes.append(f"waterfall: {name} is out of its dead-rung park; back in the chain") 

217 kept[name] = rec 

218 retval = (kept, changed) 

219 return retval

238def _budget_parked(): 

239 """Vendor -> expiry, with anything already expired dropped. Pruning on read 

240 is what makes a vendor come back: no timer, no background task -- the first 

241 turn after the window simply stops seeing it as parked.""" 

242 now = time.time() 

243 dropped = [] 

244 

245 def _prune(raw): 

246 raw = raw or {} 

247 live = {name: until for name, until in raw.items() 

248 if isinstance(until, (int, float)) and until > now} 

249 dropped.extend(set(raw) - set(live)) 

250 return live 

251 # Prune and write back in one locked step, so a park landing in between is 

252 # not overwritten by this thread's older copy (#363). Read-only when 

253 # nothing expired: the common turn should not rewrite the file. 

254 raw = state.get(_STATE_KEY) or {} 

255 if any(not (isinstance(u, (int, float)) and u > now) for u in raw.values()): 

256 live, _ = state.update(_STATE_KEY, _prune) 

257 else: 

258 live = dict(raw) 

259 for name in dropped: 

260 logging.info("waterfall: %s is out of its park window; back in the chain", name) 

261 retval = live 

262 return retval

266 """The configured waterfall minus parked vendors -- but never empty. A fully 

267 parked chain still has to try: refusing to answer is worse than one wasted

269 parked = _parked() 

270 live = [v for v in config.WATERFALL if v.get("name") not in parked]

273 live = list(config.WATERFALL) 

274 retval = live 

275 return retval

278def _park_until(message): 

279 """When the vendor says it will be back, honour that; otherwise use the 

280 configured window. A date we cannot parse falls back to the window rather 

281 than being trusted -- a mis-parse could park a vendor for a year. A date 

282 past `_MAX_PARK_SEC` is clamped to it, for the same reason.""" 

283 now = time.time() 

284 match = _REGAIN_DATE.search(message or "") 

285 if match: 

286 try: 

287 when = datetime.datetime( 

288 int(match.group(1)), int(match.group(2)), int(match.group(3)), 

289 tzinfo=datetime.timezone.utc, 

290 ).timestamp() 

291 date = match.group(0).split("on ")[1] 

292 if when > now + _MAX_PARK_SEC: 

293 days = _MAX_PARK_SEC // 86400 

294 retval = (now + _MAX_PARK_SEC, 

295 f"for {days} days (the vendor said until {date}, past the {days}-day cap)") 

296 return retval 

297 if when > now: 

298 retval = (when, f"until {date}") 

299 return retval 

300 except ValueError: 

301 logging.warning("waterfall: unparseable regain date; using the default window") 

302 retval = (time.time() + config.BUDGET_PARK_SEC, f"for {config.BUDGET_PARK_SEC}s") 

303 return retval

320def _vendor_for(deployment, exc=None): 

321 """Which configured vendor this failure belongs to. 

322 

323 Exact match on the deployment string first. Only if that is unavailable do we 

324 fall back to provider+suffix matching. Either way a string that matches more 

325 than one vendor identifies none of them -- parking the wrong vendor would 

326 take a working rung out of the chain, which is worse than not parking at 

327 all, and that holds for an exact match as much as for a suffix (#289).""" 

328 if deployment: 

329 # Same ambiguity rule as the suffix branch below (#289). Two rungs may 

330 # legitimately share a `model` and differ only in api_key or api_base -- 

331 # the same model on two accounts, for rate limits that throttle 

332 # independently, is a normal reason to add a fallback. Returning the 

333 # first match then parks whichever rung happens to be listed first, 

334 # every time, and the one taken out of the chain is the one that works. 

335 matches = [v.get("name") for v in config.WATERFALL 

336 if v.get("model") == deployment] 

337 if len(matches) == 1: 

338 retval = matches[0] 

339 return retval 

340 if len(matches) > 1: 

341 logging.warning( 

342 "waterfall: deployment %r matches %d configured vendors; not " 

343 "parking any -- give them distinct models", deployment, len(matches)) 

344 retval = None 

345 return retval 

346 model = str(getattr(exc, "model", "") or "") 

347 provider = str(getattr(exc, "llm_provider", "") or "") 

348 if model: 

349 matches = [v.get("name") for v in config.WATERFALL 

350 if v.get("model") == model 

351 or (v.get("model", "").endswith("/" + model) 

352 and (not provider or v.get("model", "").startswith(provider + "/")))] 

353 if len(matches) == 1: 

354 retval = matches[0] 

355 return retval 

356 if len(matches) > 1: 

357 logging.warning( 

358 "waterfall: %r matches %d configured vendors; not parking any", model, len(matches)) 

359 retval = None 

360 return retval 

361 retval = None 

362 return retval

365def _answering_vendor(resp): 

366 """Which configured vendor answered, from the response. 

367 

368 `model` alone is not enough for the same reason `_deployment_of` exists: 

369 litellm strips the provider prefix, so two vendors reached through 

370 different routers report the same string. The deployment id the Router 

371 used -- `primary`, `fb0` -- is positional, and `_RUNG_VENDORS` records what 

372 those positions meant *when that Router was built*: parking a vendor 

373 rebuilds and renumbers, so resolving against the live waterfall would 

374 credit a response in flight to whoever now holds its id.""" 

375 try: 

376 hidden = getattr(resp, "_hidden_params", None) or {} 

377 dep = str(hidden.get("model_id") or "") 

378 if dep in _RUNG_VENDORS: 

379 return _RUNG_VENDORS[dep] 

380 model = str(getattr(resp, "model", "") or "") 

381 matches = [v.get("name") for v in config.WATERFALL 

382 if v.get("model") == model or v.get("model", "").endswith("/" + model)] 

383 retval = matches[0] if len(matches) == 1 else None 

384 return retval 

385 except Exception: 

386 return None

389def is_budget_error(exc): 

390 """A 402, or a 400/403 that names a spend problem. A 402 needs no marker: 

391 it has no other reading, and OpenRouter's most common one -- "This request 

392 requires more credits, or fewer max_tokens ... can only afford N" -- names 

393 none, so it was re-dialled every turn. A 400 still needs one, because it is 

394 also 'your request was malformed'.""" 

395 status = getattr(exc, "status_code", None) 

396 if status == 402: 

397 retval = True 

398 return retval 

399 if status not in (400, 403): 

400 retval = False 

401 return retval 

402 text = str(getattr(exc, "message", "") or str(exc)).lower() 

403 retval = any(marker in text for marker in _BUDGET_MARKERS) 

404 return retval

407def park(exc, deployment=""): 

408 """Park the vendor that raised `exc`. Returns its name, or None when the 

409 vendor could not be identified -- in which case parking nothing is the safe 

410 choice, since parking the wrong one removes a working rung.""" 

411 if not config.BUDGET_PARK_SEC: 

412 retval = None 

413 return retval 

414 name = _vendor_for(deployment, exc) 

415 if name is None: 

416 logging.warning("waterfall: budget error from an unidentified vendor; not parking") 

417 retval = None 

418 return retval 

419 if name in _parked(): 

420 retval = name # already parked; the callback fires per attempt 

421 return retval 

422 text = str(getattr(exc, "message", "") or str(exc)) 

423 until, human = _park_until(text) 

424 _budget_parked() # prune first, so the write below carries no expired entry 

425 

426 def _park(parked): 

427 parked = dict(parked or {}) 

428 parked[name] = until 

429 return parked 

430 _, ok = state.update(_STATE_KEY, _park) # one locked step: a concurrent park is not lost (#363) 

431 if not ok: 

432 # Nothing persisted, so a rebuilt router would still call it; say so 

433 # rather than log a park that did not happen. 

434 logging.error("waterfall: %s is out of budget but the park could not be recorded", name) 

435 retval = None 

436 return retval 

437 # The message can carry the failed request; never log it (#72 covers the 

438 # handlers, this keeps the vendor's prose out of the record entirely). 

439 logging.warning("waterfall: %s is out of budget; parked %s", name, human) 

440 _invalidate() 

441 retval = name 

442 return retval

445def dead_reason(exc): 

446 """(reason, suggested slug or "") when `exc` says this rung cannot work as 

447 configured; None otherwise. The reason is a fixed label, never the vendor's 

448 text, which carries account and function ids. Both statuses need the text to 

449 say the model or endpoint itself is gone (`_DEAD_404`, `_DEAD_400`): either 

450 can also mean "this one request cannot be served".""" 

451 status = getattr(exc, "status_code", None) 

452 text = str(getattr(exc, "message", "") or str(exc)) 

453 if status == 404 and _DEAD_404.search(text) and not _LIVE_404.search(text): 

454 reason = "the vendor says this model or endpoint does not exist for this account (404)" 

455 elif status == 400 and _DEAD_400.search(text): 

456 reason = "the vendor refuses this model for this account or plan (400)" 

457 else: 

458 retval = None 

459 return retval 

460 match = _SUGGESTED_SLUG.search(text) 

461 retval = (reason, match.group(1).rstrip(".") if match else "") 

462 return retval

465def retry_delay(exc): 

466 """Seconds a 429 asks the caller to wait before asking again, or None when 

467 it is not a 429 or names no delay. RetryInfo's `retryDelay` in the error 

468 text first (Gemini), then a `retry-after-ms` / `retry-after` header in 

469 seconds; an HTTP-date Retry-After is not parsed. Never below 1s.""" 

470 if getattr(exc, "status_code", None) != 429: 

471 retval = None 

472 return retval 

473 seconds = None 

474 match = _RETRY_DELAY.search(str(getattr(exc, "message", "") or str(exc))) 

475 if match: 

476 seconds = float(match.group(1)) 

477 else: 

478 headers = getattr(exc, "litellm_response_headers", None) 

479 if headers is None: 

480 headers = getattr(getattr(exc, "response", None), "headers", None) 

481 try: 

482 ms = headers.get("retry-after-ms") if headers is not None else None 

483 sec = headers.get("retry-after") if headers is not None else None 

484 if ms is not None: 

485 seconds = float(ms) / 1000 

486 elif sec is not None: 

487 seconds = float(sec) 

488 except (AttributeError, TypeError, ValueError): 

489 seconds = None 

490 if seconds is None or not math.isfinite(seconds) or seconds < 0: 

491 retval = None 

492 return retval 

493 retval = max(1, math.ceil(seconds)) 

494 return retval

503def kill(exc, deployment=""): 

504 """Park the rung that raised `exc` as dead and say so at ERROR. Returns its 

505 name, or None when `exc` is not a dead-rung error or the rung cannot be 

506 identified (parking a guess would take a working rung out). 

507 

508 The park doubles per repeat within the record's history window, from 

509 `_DEAD_PARK_FIRST` to `_DEAD_PARK_MAX`. With parking off 

510 (`budget_park_sec: 0`) nothing is parked, but the rung is still logged and 

511 announced -- once per history window, since an unparked rung fails every 

512 turn.""" 

513 found = dead_reason(exc) 

514 if found is None: 

515 retval = None 

516 return retval 

517 reason, suggest = found 

518 hint = f"; the vendor suggests model {suggest!r}" if suggest else "" 

519 name = _vendor_for(deployment, exc) 

520 if name is None: 

521 logging.error("waterfall: DEAD RUNG %s: %s%s -- could not tell which configured " 

522 "rung it is, so not parking it", deployment or "unknown rung", reason, hint) 

523 retval = None 

524 return retval 

525 with _DEAD_LOCK: 

526 retval = _kill_locked(name, reason, suggest, hint) 

527 return retval

530def _kill_locked(name, reason, suggest, hint): 

531 now = time.time() 

532 parking = bool(config.BUDGET_PARK_SEC) 

533 model = next((v.get("model") for v in config.WATERFALL if v.get("name") == name), "") 

534 notes, outcome = [], {} 

535 

536 def _kill(raw): 

537 records, _ = _prune_dead(raw or {}, now, notes) 

538 prior = records.get(name) 

539 if prior and (prior["until"] > now or not parking): 

540 # Dialled while parked (every rung parked, so the full chain is 

541 # tried; or a call already in flight), or parking is off. Already 

542 # announced. 

543 outcome["again"] = True 

544 return records 

545 strikes = (prior.get("strikes") or 1) + 1 if prior else 1 

546 window = min(_DEAD_PARK_FIRST * 2 ** (strikes - 1), _DEAD_PARK_MAX) if parking else 0 

547 records[name] = {"until": now + window, "model": model, "reason": reason, 

548 "suggest": suggest, "told": False, "strikes": strikes, 

549 "back": not parking} # nothing parked, so nothing to come back from 

550 outcome["window"] = window 

551 return records 

552 # The whole read, decision and write in one state transaction (#363). 

553 _, ok = state.update(_DEAD_KEY, _kill) 

554 for line in notes: 

555 logging.info(line) 

556 if outcome.get("again"): 

557 logging.warning("waterfall: %s failed again and is still dead: %s", name, reason) 

558 retval = name 

559 return retval 

560 if not ok: 

561 action = "could not record it in the state file, so not parking it" 

562 elif parking: 

563 action = f"skipping it for {_hours(outcome['window'])}" 

564 else: 

565 action = "not parking it (budget_park_sec is 0)" 

566 logging.error("waterfall: DEAD RUNG %s (%s): %s%s; %s -- fix or remove it in the " 

567 "waterfall config", name, model, reason, hint, action) 

568 if parking and ok: 

569 _invalidate() 

570 retval = name 

571 return retval

574def claim_dead_notices(): 

575 """Markdown lines for dead rungs not yet announced, marked announced. 

576 

577 The Slack ingest posts them in the thread of the turn that just ended, so 

578 the notice reaches an operator without a new transport -- Slack only: a 

579 Signal group on a shared account is no place for an operator notice. Once 

580 per park: the flag lives in the state file, so a restart neither repeats 

581 nor loses one. The line names the rung, never its model string, which for 

582 some providers carries a cloud account id; the model is in the ERROR log 

583 line.""" 

584 with _DEAD_LOCK: 

585 retval = _claim_locked() 

586 return retval

589def _claim_locked(): 

590 now = time.time() 

591 notes, lines = [], [] 

592 

593 def _claim(raw): 

594 records, _ = _prune_dead(raw or {}, now, notes) 

595 del lines[:] 

596 for name, rec in records.items(): 

597 if rec.get("told"): 

598 continue 

599 records[name] = dict(rec, told=True) 

600 if not config.BUDGET_PARK_SEC: 

601 action = "Parking is off, so it is still being tried" 

602 elif rec["until"] > now: 

603 action = f"Skipping it for {_hours(rec['until'] - now)}" 

604 else: 

605 action = "Its park has run out, so it is being tried again" 

606 line = (f"\U0001F6A8 LLM rung **{name}** is dead: {rec.get('reason')}. " 

607 f"{action}; fix or remove it in the waterfall config.") 

608 if rec.get("suggest"): 

609 line += f" The vendor suggests `{rec['suggest']}`." 

610 lines.append(line) 

611 return records 

612 # Mark and claim in one state transaction: of two processes claiming at 

613 # once, the second sees told=True and gets nothing (#363). Nothing to 

614 # announce unless the mark landed, or a later claim would repeat it. Skip 

615 # the write entirely when there is nothing unannounced. 

616 pending = any(isinstance(r, dict) and not r.get("told") 

617 for r in (state.get(_DEAD_KEY) or {}).values()) 

618 retval = [] 

619 if pending: 

620 _, ok = state.update(_DEAD_KEY, _claim) 

621 for line in notes: 

622 logging.info(line) 

623 retval = list(lines) if ok else [] 

624 return retval

627class _BudgetWatch(CustomLogger): 

628 """Park on litellm's per-deployment failure callback. 

629 

630 This is the only hook that sees a failure the fallbacks went on to cover -- 

631 and that is the whole case: the turn still gets answered, so nothing raises, 

632 yet the exhausted vendor must not be dialled again next turn.""" 

633 

634 def log_failure_event(self, kwargs, response_obj, start_time, end_time): 

635 _on_failure(kwargs) 

636 

637 async def async_log_failure_event(self, kwargs, response_obj, start_time, end_time): 

638 _on_failure(kwargs)

641def _on_failure(kwargs): 

642 exc = kwargs.get("exception") 

643 if exc is None: 

644 return 

645 if isinstance(exc, litellm.Timeout): 

646 # Named in the log the way parking is (#125): a rung that keeps timing 

647 # out should be visible as a pattern, not as stack traces. 

648 logging.warning("waterfall: %s timed out; failing over", _deployment_of(kwargs) or "unknown rung") 

649 return 

650 if is_budget_error(exc): 

651 park(exc, _deployment_of(kwargs)) 

652 return 

653 if dead_reason(exc) is not None: 

654 kill(exc, _deployment_of(kwargs)) # logs itself: ERROR when new, WARNING when again 

655 return 

656 if getattr(exc, "status_code", None) == 404: 

657 # A 404 the dead-rung rules do not recognise (#351): litellm cools it 

658 # for 60s and the chain moves on, so it costs nothing visible -- which 

659 # is how a retired slug sat in the chain unnoticed. No network check at 

660 # startup can tell a dead slug from a live one, so say it here, where 

661 # the vendor has just said it. 

662 logging.warning("waterfall: %s answered 404 (%s); failing over. If this repeats, " 

663 "check its model slug in the waterfall config", 

664 _deployment_of(kwargs) or "unknown rung", type(exc).__name__) 

665 return 

666 # Named too. When a fallback covers the failure nothing raises and 

667 # litellm logs nothing at WARNING, so a rung that was rate-limited, 

668 # erroring or holding a bad key left no trace at all. Type and status 

669 # only: the message can carry the failed request (#72). 

670 logging.warning("waterfall: %s failed (%s %s)", _deployment_of(kwargs) or "unknown rung", 

671 type(exc).__name__, getattr(exc, "status_code", None) or "no status") 

672

689def _deployment(model_name, vendor): 

690 # A subscription rung (codex, #35) has no api_key at all: it authenticates 

691 # from the CLI's own token file. Sending `api_key: None` is not the same as 

692 # omitting it -- litellm treats the key as present-but-empty. 

693 params = {"model": vendor["model"]} 

694 # Every rung gets a per-request ceiling (#125): a rung that hangs must 

695 # become a Timeout the Router can fail over, not a held turn. 

696 params["timeout"] = vendor.get("timeout_sec") or config.WATERFALL_TIMEOUT 

697 if vendor.get("api_key"): 

698 params["api_key"] = vendor["api_key"] 

699 if vendor.get("api_base"): 

700 params["api_base"] = vendor["api_base"] 

701 retval = {"model_name": model_name, "litellm_params": params} 

702 return retval

711def _build_with_rungs(): 

712 """(Router, its rungs as `[(id, vendor, litellm_params)]`), from one read of 

713 the live waterfall, so the two always describe the same chain (#351).""" 

714 _watch() 

715 # Registered before the Router is built, not at import: a `codex/` row is 

716 # optional, and litellm must know the prefix by the time it resolves one. 

717 codex_llm.register() 

718 wf = _live_waterfall() 

719 if not wf: 

720 raise SystemExit("config waterfall is empty -- add at least one vendor") 

721 model_list = [_deployment("primary", wf[0])] 

722 rest = wf[1:] 

723 for i, vendor in enumerate(rest): 

724 model_list.append(_deployment(f"fb{i}", vendor)) 

725 # Which rung is which, fixed at build time (#190). Reading it back from the 

726 # live waterfall at attribution time is a race: parking a vendor rebuilds 

727 # the Router and renumbers the rungs, so a response already in flight would 

728 # be credited to whichever vendor now holds its id. The ids are positional, 

729 # and this is the only place that knows what they meant. 

730 global _RUNG_VENDORS 

731 _RUNG_VENDORS = {m["model_name"]: (wf[0] if m["model_name"] == "primary" 

732 else rest[int(m["model_name"][2:])]).get("name") 

733 for m in model_list} 

734 # The chain starts at fb0, not at the primary (#351): `complete()` asks the 

735 # primary alone, so it can wait out a short 429 before anything falls over, 

736 # and then hands the request to fb0 with the rest behind it. 

737 rungs = [(m["model_name"], (wf[0] if m["model_name"] == "primary" 

738 else rest[int(m["model_name"][2:])]).get("name"), 

739 dict(m["litellm_params"])) 

740 for m in model_list] 

741 fallbacks = [{"fb0": [f"fb{i}" for i in range(1, len(rest))]}] if len(rest) > 1 else [] 

742 router = Router( 

743 model_list=model_list, 

744 fallbacks=fallbacks, 

745 num_retries=1, 

746 cooldown_time=60, 

747 # Cool a rate-limited deployment on the FIRST 429 rather than after the 

748 # default fail threshold (#51). A Slack agent's traffic is bursty and 

749 # low-volume: by the time a threshold is reached the burst is over, and 

750 # every fail in it was a wasted round-trip. 

751 allowed_fails=0, 

752 ) 

753 retval = (router, rungs) 

754 return retval

757def _ensure(): 

758 """Build the router, or rebuild it when the set of usable vendors changed -- 

759 a park added one, or a park expired and gave one back. Returns the router 

760 and its rungs as built, `[(id, vendor, litellm_params), ...]`, together: 

761 a rebuild renumbers the rungs, so they are only meaningful for that router.""" 

762 global _LIVE 

763 with _BUILD_LOCK: 

764 live = _LIVE 

765 vendors = tuple(v.get("name") for v in _live_waterfall()) 

766 if live is None or vendors != live[2]: 

767 if live is not None: 

768 logging.info("waterfall: rebuilding, chain is now %s", " -> ".join(vendors)) 

769 router, rungs = _build_with_rungs() 

770 # The vendors key is what was actually built, not the read above: 

771 # a park landing in between would otherwise mislabel this router. 

772 live = (router, rungs, tuple(vendor for _id, vendor, _params in rungs)) 

773 _LIVE = live 

774 retval = (live[0], live[1]) 

775 return retval

778def _retry_primary(exc, rung, kwargs): 

779 """Wait out a short 429 on the primary and ask it once more (#351). Returns 

780 the response, or None when there is nothing to wait for or the retry failed 

781 too -- either way the caller falls over to the rest of the chain. 

782 

783 The retry goes to litellm directly, not through the Router: the Router has 

784 already cooled the deployment for `cooldown_time`, longer than the delay 

785 being honoured, and would refuse it without dialling. The failure callback 

786 still sees a failed retry -- `metadata.deployment` is what it identifies the 

787 rung by -- so a budget or dead-rung error here parks as it would anywhere.""" 

788 delay = retry_delay(exc) 

789 _rung_id, vendor, params = rung 

790 if delay is None: 

791 retval = None 

792 return retval 

793 if delay > _RETRY_WAIT_CAP: 

794 logging.warning("waterfall: %s is rate-limited for %ss, past the %ss wait cap; " 

795 "failing over", vendor, delay, _RETRY_WAIT_CAP) 

796 retval = None 

797 return retval 

798 logging.warning("waterfall: %s is rate-limited; retrying it in %ss before failing over", 

799 vendor, delay) 

800 time.sleep(delay) 

801 try: 

802 resp = litellm.completion(**params, **kwargs, metadata={"deployment": params.get("model")}) 

803 except Exception as again: # noqa: BLE001 -- the chain is still there to try 

804 logging.warning("waterfall: %s failed again after the wait (%s %s); failing over", 

805 vendor, type(again).__name__, 

806 getattr(again, "status_code", None) or "no status") 

807 retval = None 

808 return retval 

809 logging.info("waterfall: %s answered after the wait", vendor) 

810 # The Router still has the primary cooled for the rest of `cooldown_time`, 

811 # so every later step of this turn would skip a rung that just answered. 

812 # A rebuild drops that cooldown (and the other rungs' 60s ones -- see the 

813 # module docstring for why that is a rounding error). 

814 _invalidate() 

815 retval = resp 

816 return retval

819def complete(messages, tools=None): 

820 """Return the raw assistant message (has .content and .tool_calls). 

821 

822 The primary is asked alone first, so a short 429 can be waited out on it 

823 before anything falls over (#351); then fb0, with the rest of the chain as 

824 its fallbacks. Everything else is the Router's, as before. 

825 

826 No try/except for budget errors here on purpose: when a fallback covers the 

827 failure nothing is raised, so parking lives in the failure callback instead. 

828 An exception reaching this caller means the whole chain failed, which parking 

829 cannot rescue -- the vendors are already parked by the callback, and the next 

830 turn rebuilds without them.""" 

831 kwargs = {"messages": messages} 

832 if tools: 

833 kwargs["tools"] = tools 

834 router, rungs = _ensure() 

835 try: 

836 # num_retries=0: with no fallbacks behind it the Router would re-dial a 

837 # 429'd primary at once, which is neither the wait nor the failover. 

838 resp = router.completion(model=rungs[0][0], num_retries=0, **kwargs) 

839 vendor = None 

840 except Exception as exc: 

841 resp = _retry_primary(exc, rungs[0], kwargs) 

842 if resp is None and len(rungs) < 2: 

843 raise 

844 vendor = rungs[0][1] if resp is not None else None 

845 if resp is None: 

846 resp = router.completion(model=rungs[1][0], **kwargs) 

847 # What it cost, on the rung that actually answered (#190). The Router may 

848 # have failed over, so the vendor is read back off the response rather than 

849 # assumed to be the primary. A direct retry carries no Router id, so it is 

850 # credited to the rung it was sent to. 

851 cost.note(resp, vendor or _answering_vendor(resp)) 

852 retval = resp.choices[0].message 

853 return retval
